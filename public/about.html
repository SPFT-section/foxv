About Fox-V

Everything you need to know about this reading site.

What is Fox-V?

An offline-first novel reading website in the WTR-Lab style — community requests, reader customization, machine translation — but fully self-contained: separate pages, shared stylesheets, and plain JavaScript, no frameworks, no build step.

Features — everything, WTR-Lab style

  • Community requests — suggest novels (raw source URLs welcome); requests queue locally until the optional backend deploys.
  • Following & folders — follow novels with a heart, organize your library into custom folders.
  • Filters & sort — genre chips, following-only, continue-reading rows, sort by title/author/progress.
  • Reader customization — font family, font size, line height, quote styles (smart “”, 「」, 『』, 【】), sepia/dark/light themes, custom page & text colors.
  • Machine translation — Google Translate in 14 languages, re-translate button, per-chapter cache.
  • Progress — per chapter and per book, synced when the API is live (localStorage otherwise).
  • PWA — installable, works offline.

Site structure

  • index.html — Library: new novels, continue-reading, genre filters, sort, folders, community requests, ranking.
  • novel.html — Novel detail: cover, stats, follow, full chapter list.
  • reader.html — Reader: chapter sidebar, full customization panel, translation.
  • about.html — this page.
  • css/ — base.css (theme variables) and style.css (components).
  • js/ — data.js (novel content), icons.js (SVG icon library), common.js (theme, storage, PWA), db.js (sync), library.js, reader.js, novel.js.
  • server.js + package.json — Node/Express API connected to PostgreSQL.
  • manifest.webmanifest + sw.js — installable PWA with offline caching.

Design

  • WTR-Lab style: flat cards, Nunito Sans + JetBrains Mono typography, brand-orange accents, dark mode.
  • Self-contained SVG icon library (js/icons.js) — no external CDN, works offline.
  • Responsive layout for phones, tablets, and desktops.

Translation — the unique angle

Most novel readers are locked to one language. Fox-V's original angle: read any chapter in your language, instantly. Pick a language in the reader and the chapter is machine-translated via Google Translate — powered entirely on the free tier, no backend needed (the browser talks to Google's endpoint directly; the optional /api/translate route remains available for when a server key is configured). Translations are cached per chapter and language, and the font size is kept.

  • 14 languages: ไทย, 中文, 日本語, 한국어, Español, Français, Deutsch, Русский, Bahasa Indonesia, Tiếng Việt, العربية, Português, हिन्दी + original English.
  • Choice is remembered between sessions; cached translations work offline after first read.
  • Bilingual fallback: if the translation service is unreachable, the original text stays.

Database

Reading progress is stored in localStorage out of the box. When the Express API (server.js, wired to free-tier PostgreSQL on Render) is deployed, progress also syncs to the database so it follows you across devices — js/db.js gracefully falls back to local storage whenever the API is unreachable. Each visitor gets an anonymous reader ID — no accounts required.

Content

Includes three sample novels with original placeholder chapters so the reader is fully demonstrable out of the box.

Run it locally

  • python3 -m http.server 8000 → http://localhost:8000 (frontend only)
  • npm install && DATABASE_URL=... node server.js (API)

The frontend works without the API too — progress then stays in the local browser cache.
